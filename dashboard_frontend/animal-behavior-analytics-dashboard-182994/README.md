# Animal Behavior Analytics Dashboard

This repository contains the frontend dashboard for detecting animal behaviors, including user authentication, dashboard KPIs, video management, and analytics report exports.

- Frontend: animal-behavior-analytics-dashboard-182994/dashboard_frontend
- To run: see the frontend README for setup and mock API instructions.

## Overview

The application provides:
- User authentication (login/register)
- Protected dashboard with summary KPIs and latest activity
- Videos page for upload, list, and processing status
- Analytics page for viewing and exporting behavior reports

See the frontend README in dashboard_frontend/ for full details on running with mock data and environment variables.
